# v0.3.0 模拟外部接口与全场景验收更新报告

发布日期：2026-07-13

升级基线：`v0.2.0` 清理与结构重构结果。

版本范围：Python 后端、响应域数据库、模拟数据集、主前端、浏览器验收、PostGIS 影子迁移、CI、OpenAPI 和运维/验收文档。

## 1. 更新摘要

本版本完成渐进式设计中尚缺的外部接口故障矩阵、24 项正式模拟场景目录与逐场景自动化追溯，并把真实 Chromium 验收纳入仓库及 CI。版本号由 `0.2.0` 升至 `0.3.0`。

全仓可删除性审计按“引用、运行入口、构建合同、验收证据”四项判断：`v2`/`v3` 兼容层、数据管道、SSE、迁移和评测脚本均仍有运行或测试引用，因此保留；删除 4 个所在目录已有真实文件、已失去占位作用的 `.gitkeep`。上一版本已删除 36 个过期/重复文档和生成物，详见 `v0.2.0.md`。

## 2. 功能变动

### 2.1 模拟任务下发与回调

- 模拟网关覆盖正常、超时、拒收、部分成功、重复回调和乱序回调六类确定性故障。
- Outbox 新增 `partially_sent`、网关状态、场景、外部请求、Trace 和回调计数；超时保持可重试，拒收失败关闭，部分成功保留人工协调语义。
- 新增异步回调记录表、唯一幂等键、外部版本与顺序状态；重复回调合并，乱序回调记录但不覆盖历史。
- 新增回调查询和模拟回调入口；回调只能增加证据与审计，不能直接修改任务正式状态。
- 指标新增部分成功、人工接管和回调总量。

### 2.2 FloodAgent-Bench

- 数据集升级为 `floodagent-bench-v2`，新增稳定 `dataset_id`、生成器版本、`SYNTHETIC` 来源和数据卡校验和。
- 生成设计文档列出的 24 个正式 `SimulationScenario`；每项包含输入、候选对象、字段与证据、冲突/缺失、合法路径、拒绝操作、错误码和验收断言。
- 对象、事件、预警、场景及候选评测记录统一携带来源、版本、模拟标记和数据来源。
- 新增 24/24 场景—测试节点追溯报告，CI 确定性再生并逐字节对比，防止场景目录只有元数据而缺少行为证据。
- 新增第 18—23 节机器可读完成性审计，校验软件、数据实验、文档、OpenAPI、Compose、Gate 0/1/2、性能和外部 No-Go 边界，并由 CI 确定性重建。
- 导入真实模型原始消融、K 敏感性和 80 组参数网格，并新增不复用 Cross-Encoder 分数的 BGE 双编码器 `w/o Reranker` 逐用例实验；另在 Google CONFLICTS 的 458 例冻结真实模型候选池完成 `w/o Conflict`。Full 仍未优于 `w/o Role` 或 `w/o Conflict`，不得虚构为通过。
- 新增 HousingQA 公开专家字段/辖区消融：40 个确定性复合用例覆盖 160 字段、22 辖区和 2021 快照；Full 相对 `w/o Field` 字段覆盖提高 0.050000（95% CI [+0.018750, +0.087500]），相对无辖区过滤提高 0.175000，但与最强字段分解基线持平，Answer Accuracy 仅 0.306250。
- 新增 LawShift 跨版本消融：固定 Apache-2.0 数据提交，124 例覆盖 31 类专家审阅假设修订和修订前/后快照；Full 相对无版本过滤的精确版本证据提高 0.137097（95% CI [+0.080645, +0.201613]）、错误版本率降低 0.451613，但 Article Recall@1 下降 0.064516，且与公平的适用性过滤 Cross-Encoder 基线完全持平。数据没有权威生效/失效日期。
- 新增 EUR-Lex/CELLAR 权威生效/失效边界消融：固定 30 对唯一相邻废止边界、60 例和 360 个候选出现；Full 相对无适用性过滤的精确证据提高 0.516667（95% CI [+0.383333, +0.650000]），无效适用率降低 0.516667，但与获得相同日期元数据的公平过滤 Cross-Encoder 同为 1.000000。
- 跨适用公开集的 9/9 命名消融均有真实模型执行工件，辖区、版本替换和权威生效/失效日期三部分构造均可识别；完成度仍为 `PARTIAL`，因为不同构造分布在不同领域、字段/角色权重仍为受控诊断，且真实防汛领域双专家评判未完成。
- 基于同一保存分数补齐三数据集 512/1024/2048 Token 预算和 ConditionalQA 0/25/50/75% 缺失比例敏感性，强制零超预算并披露错误完整声明率。
- 新增 ConditionalQA 64/128/256-token、20% overlap 的真实 reranker 分块长度敏感性；逐档重新计算问题与五类角色分，按父证据去重评价并披露固定 Top-K 的重复父证据成本。
- 将 FRC 字段、角色、可信度、适用性、新颖性、支持度、冲突和成本系数固化为可审计的 `EvidenceSelectionPolicy`；新增 3 例、18 文档、16 项“字段→金证据”映射的 `SYNTHETIC` 参数辨识基准和字段/角色权重、冲突阈值单因素扫描，金映射只用于评分、不传入选择器。扫描发现角色权重 0 会降低角色覆盖，字段权重 0 只降低选择器自报覆盖而不改善金标准覆盖；字段权重 8 或冲突阈值不低于 0.5 会使 Evidence F1/金标准字段覆盖从冻结策略的 0.750000/0.773810 降至 0.607143/0.573810，并使 1/3 用例选入冲突候选；该产物明确不计为公开真实模型 Gate 2 证据。
- 新增 CONFLICTS 真实模型冲突消融与阈值扫描：`w/o Conflict` 只移除 `alternative_claim`、`temporal_validity`，36/458 例选择变化；Full/消融准确率 0.334061/0.338428，Full−消融 -0.004367，95% CI [-0.013100, +0.004367]。冲突角色阈值 0.25/0.40/0.55/0.70/0.85 的准确率为 0.336245/0.336245/0.334061/0.334061/0.325328；该事后诊断不支持 Gate 2 放行。
- 修正弱冲突启发式：否定词差异只有在共享任务字段且至少一方低可信时才触发弱冲突惩罚，避免把官方“关闭道路”条款因单纯含否定/关闭标记而误罚；同时支持显式 `conflict_risk_score` 并在选择 trace 中同时保留原始与阈值后冲突分。

### 2.3 风险对象主数据与异常闭环

- 风险对象增加规范对象 ID、别名、重复来源、台账状态和有效期；重复台账合并到规范对象并保留来源和不可变版本记录。
- 过期或停用台账标记为 STALE，禁止直接确认；缺失对象支持人工补录后再由复核岗确认。
- 补齐缺坐标排除、非法坐标系、四类时限、核验退回整改以及文档解析/索引依赖失败的直接自动化证据。

### 2.4 前端与可视验收

- 下发监控显示部分成功、人工接管、故障场景、尝试次数和回调数量。
- 引入固定版本 Playwright，验证模拟水印、事件版本/来源、受控危险操作理由、桌面与 390px 移动布局、横向溢出和控制台错误。
- Vitest 明确只扫描 `src/` 单元规格，和 E2E 测试职责分离；React Router 显式启用 v7 兼容标志，消除未来行为警告。
- 修复生产 Nginx 中 `/response/` API 代理与同名 SPA 页面冲突；业务 API 统一经 `/api/*`，`/response` 现在稳定回落到前端路由。
- 新增模拟下发场景控制台，可选择六类故障并查看回调版本、顺序、状态和 Trace；页面开关 `VITE_RESPONSE_WORKBENCH_ENABLED` 支持失败时回退旧风险调度页。
- Chromium 同时归档新版响应工作台和旧页面回退截图，CI 证据保留 30 天。

### 2.5 数据与迁移

- SQLite 新增 `response_dispatch_callbacks` 及查询索引，并纳入备份、密钥轮换和加密迁移保护范围。
- PostGIS 映射升级到 `sqlite-response-to-postgis-shadow-v2`，加入 Outbox 与回调投影；受控夹具为 12 类、28 条、0 隔离。
- OpenAPI 快照已按新增模型、角色和路由重新生成，CI 继续执行确定性差异检查。

## 3. 代码结构与文件清理

- 下发故障生成保持在确定性模拟模块，正式状态编排保持在 `ResponseWorkflowService`，持久化逻辑集中在 `ResponseRepository`，HTTP 身份边界集中在响应路由。
- 删除 4 个冗余目录占位文件；缓存、数据库、浏览器 trace、构建目录、GLB、PBF 和本机 `api_key.txt` 继续由 `.gitignore` 隔离，不进入 Git。
- 全仓 Ruff、Python 编译、TypeScript 未使用检查和构建通过；未发现可安全删除且无引用的业务模块。

## 4. 系统性能

环境为 Windows 单进程 FastAPI TestClient、加密 SQLite、签名身份和 nonce 防重放；每条路径 40 次采样。结果只用于仓库回归，不代表生产容量。

| API | v0.2 P95 | v0.3 P95 | 变化 | 预算 | 错误率 |
|---|---:|---:|---:|---:|---:|
| event list | 12.159 ms | 12.816 ms | +5.4% | 150 ms | 0 |
| event dashboard | 28.725 ms | 30.641 ms | +6.7% | 250 ms | 0 |
| event timeline | 27.842 ms | 27.958 ms | +0.4% | 200 ms | 0 |
| audit trail | 31.141 ms | 31.603 ms | +1.5% | 300 ms | 0 |

四条路径共 160 次请求全部通过预算且无错误；相对 v0.2 的变化远低于已冻结预算，且受本机单进程抖动影响，不外推为生产容量。主前端 JavaScript 生产输出约 5.24 MB，其中 Cesium 运行时仍约 4.73 MB，是后续按需加载的主要优化点。

HousingQA、LawShift 与 EUR-Lex 评测器都是离线脚本，不进入 FastAPI 请求热路径，不改变上述 API 预算。冻结本地 GPU 运行中，HousingQA 的 BGE/重排/Qwen 全流程约 376.6 秒，LawShift 的 992 个 Cross-Encoder 候选对约 67.9 秒；EUR-Lex 对 360 个候选进行真实重排，但本轮未采集独立稳定计时，不能补写耗时。这些运行只说明评测复现成本，不是线上吞吐指标。EUR-Lex 提交的源选择清单约 55 KB，汇总 JSON 约 7 KB、逐例 gzip 约 4 KB；原始网页、公开数据与模型缓存继续留在 `.cache/`，不进入发行包。

## 5. 安全性改动

- 新增 `external_service` 最小权限身份，只允许访问模拟回调入口；尝试读取事件或调用其他响应接口返回 403。
- 回调同时校验可信身份、模拟专用 Mock Token、`is_simulated` 和请求头/载荷幂等键；生产环境明确拒绝该入口。
- 外部版本、唯一幂等索引和事务写入共同处理重复/并发回调；竞态下返回已存在记录并追加安全审计。
- 模拟网关继续硬拒绝 HTTP(S) 等真实目的地，下发前继续验证审批载荷 SHA-256。
- 主前端与 Cesium `npm audit --audit-level=high` 均为 0 个已知漏洞；自动扫描不能替代第三方渗透测试和生产 IdP/TLS/KMS 评审。
- 从空 venv 安装 `.[test,postgres]` 后执行 pip-audit 2.10.1，项目隔离依赖为 0 个已知漏洞；本机 Anaconda 全局环境另有 44 个非项目旧包的 162 条公告，已在供应链审计报告中单独披露。
- HousingQA 与 LawShift 输入固定到精确公开提交、许可和 SHA-256；EUR-Lex 输入固定 SPARQL 查询、CELEX、日期、官方 URL 以及原始 HTML/规范文本 SHA-256。导入器从逐例 gzip 重算聚合、配对 bootstrap、最强基线和分层覆盖，汇总值或压缩工件被篡改时失败关闭。
- HousingQA gold 答案/字段证据映射、LawShift charge/prison labels 及 EUR-Lex CELEX 替换关系均只用于事后评分；EUR-Lex 查询不含 gold CELEX，只有 Full 和公平过滤基线能读取相同有效期元数据。自动测试验证标签隔离与源文本漂移拒绝，降低评测泄漏和来源替换风险。

## 7. 兼容性、回滚与剩余边界

- `/response/*`、`/api/v1/*`、`/platform/*` 和 `/agent-twin/*` 现有入口保持；新增接口是向后兼容扩展。
- 数据库表由启动迁移幂等创建；回滚应用版本时应先停止回调写入，新增表可保留，不需破坏性删除。
- PostGIS 仍是单向影子投影，SQLite 仍为权威状态源；未通过真实迁移 Gate 前不得切换。
- Gate 2 保持 `NO-GO`：此前名为 `setr` 的实现只是覆盖贪心工程代理，不能表述为真实 SetR 复现；三套主公开数据 Evidence F1 区间均跨 0，CONFLICTS 上 FRC 低于覆盖代理。HousingQA、LawShift 与 EUR-Lex/CELLAR 证明字段、辖区、版本和权威日期过滤具有可辨识作用，但 Full 均未超过对应最强公平基线；论文 expected-behavior adherence、同一防汛领域双专家和独立人工评判尚未完成。
- 真实 GIS/预警、生产 PostgreSQL、真实 IdP/MFA、生产 TLS/KMS、跨部门下发、第三方渗透测试、异地恢复、双专家标注和真实岗位 UAT 均为外部 No-Go，不以本版本代码或模拟测试替代。
