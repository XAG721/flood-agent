# v0.3.2 FRC-RAG 实验与独立盲评基础设施更新报告

发布日期：2026-08-07

升级基线：`v0.3.1`

版本范围：FRC-RAG 可复现实验、公开数据源治理、完成度审计、CONFLICTS 独立人工盲评工具与相关文档和结果资产。

## 1. 更新摘要

本版本把 v0.3.1 之后逐步形成的 FRC-RAG 研究代码、协议、冻结结果和审计证据整理为可追溯发布快照。v89 在 IIRC 案例互斥的开发集和一次性确认集上重复建立了证据源选择优势，但该结论仅覆盖冻结候选选择器，不代表端到端答案质量、洪水领域有效性或生产可用性。

系统 Gate 2 继续保持 `NO-GO / SHADOW`。CANARY、DEFAULT 和生产切流均未获授权。

## 2. 功能与研究资产变动

- 新增公开数据源登记、下载指纹、样本隔离、预注册、开发/确认开封、结果锁定与关闭记录，覆盖 v40—v89 的渐进式评测链。
- 将实验实现收敛到 `research/frc_rag`，并为各阶段提供 `scripts/run_*.py` 可复现入口；研究依赖仍不进入 FastAPI 生产运行时默认依赖。
- v89 冻结 v88 的 154 维运行时分数特征和 ExtraTrees 基数策略，只增加低候选数量的确定性适配，没有用确认集重新训练或调参。
- 建立 458 个 CONFLICTS 案例、916 份盲化回答的人工评审包，按两名独立评审者和一名独立裁决者分配 24 个可恢复批次。
- 新增本地人工评审工作站、私有草稿与回执、批次收集、评审者内一致性检查和盲映射开启前校验。空白模板、自动化探针和合成测试结果均不会被计作人工证据。
- 完成度审计增加研究协议、源登记、执行结果、文件哈希、后继状态和外部条件的逐项追踪。

## 3. 研究结果

| 阶段 | 案例数 | v89 F1 | `frc_fixed2` F1 | 配对差值 | 95% CI |
|---|---:|---:|---:|---:|---:|
| IIRC 开发 | 800 | 0.636527 | 0.606125 | +0.030402 | [+0.017976, +0.042557] |
| IIRC 确认 | 1200 | 0.627097 | 0.598195 | +0.028902 | [+0.017896, +0.039656] |

两个阶段均通过冻结协议中的严格门槛，并且相对全部已登记对照的点差为正。该结果只能表述为“同数据集、案例互斥、冻结选择器的源选择优势复制支持”。

以下结论仍未建立：独立训练数据集迁移优势、端到端答案与引用正确性、真实 SetR 复现、洪水领域专家有效性、生产容量与机构 UAT。

## 4. 系统性能

- 本版本没有改变正式响应工作流的运行时架构，也没有把研究模型加载到 FastAPI 默认请求路径。
- FRC-RAG 指标变化来自离线候选证据选择实验，不能解释为线上 API 吞吐量或延迟改善。
- v0.3.1 的受控 API 性能预算继续作为本地回归参考；生产性能结论仍需要 PostgreSQL、真实数据规模和并发压测。
- 大型评测结果采用压缩 JSONL 或摘要报告保存；生产包继续通过 `flood_system*` 包边界排除 `research` 实验代码。

## 5. 安全性与隐私改动

- 人工评审工作站只允许绑定 `127.0.0.1`，拒绝非回环监听，并要求高熵会话令牌。
- 页面启用 HttpOnly、SameSite、CSP、`no-store`、来源校验和防嵌入策略；令牌从地址栏移除。
- 私有评审草稿、真实身份、回执、路由和合并结果只写入已忽略的 `.cache`，公开批次不包含方法身份、评分、原始样本 ID 或重复任务映射。
- 运行时校验冻结 manifest、批次文件和提交哈希；文件不匹配时失败关闭。
- 两名评审者与裁决者必须是不同人员，工具拒绝同一身份跨角色复用；任何模型或自动化填表不得替代真实人工评审。
- PostCSS 已锁定到 8.5.26，消除本次 CI 发现的高危源映射路径穿越公告。React Router 保持 6.30.4，仍有 2 个中危公告；项目未启用对应的 SSR/RSC 路径，并在依赖安全审计中记录了残余风险和后续升级条件。

这些措施降低了本地盲评泄漏和误计证据的风险，但不替代第三方渗透测试、生产 IdP/TLS/KMS、灾备演练或机构安全验收。

## 7. 回滚与剩余边界

- 应用版本可回滚到 v0.3.1；本版本没有执行破坏性数据库迁移，也没有授权删除审计历史。
- 研究结果文件应按冻结哈希保留，不得使用已揭示确认集重新包装新的独立验证。
- 人工盲评当前仅交付工具和空白批次；在三名真实人员完成评审、质量检查和裁决前，不得声称人工证据完成。
- 后续优先级为：交付 CONFLICTS 盲评包、筛选真正独立的新数据源并启动 v90、建立洪水领域双专家盲评、最后再评估 SHADOW 到 CANARY 的条件。
