# 2Wiki 残差三路由器前瞻开发实验综合报告（v81）

## 结论

v81 完成了“只使用永久排除的 v75 开发与确认历史训练残差路由器，再在新的案例互斥 2WikiMultiHopQA 样本上做冻结评测”的预注册开发实验。800 条开发样本上的候选证据宏 F1 为 `0.547195`，冻结 v75 为 `0.542751`；配对差值为 `+0.004444`，95% CI 为 `[+0.001706,+0.007381]`。增益区间为正，但低于预注册的至少 `+0.005` 要求。

状态为：

`2WIKI_V81_RESIDUAL_ROUTER_DEVELOPMENT_ADVANTAGE_NOT_ESTABLISHED_STOP`

comparison 题型上候选相对该题型最强对照为 `-0.008571`，也低于 `-0.005` 安全线。15 项严格门槛中 3 项失败，因此确认阶段没有打开，也没有选择确认 ID。非劣包络全部通过；选择器、CANARY、DEFAULT 和 Gate 2 均不授权，Gate 2 保持 `NO-GO/SHADOW`。

## 模型开发与修复

v81 以冻结 v75 路由为默认动作，只学习两个残差覆盖动作：

- `cross_override`：改走 cross-encoder top-k；
- `soft_anchor_flip_override`：在软标题闭包与交替锚点之间翻转；
- 预测增益未超过阈值时保持 `v75_default`。

训练证据严格限定为 v75 开发与确认共 1600 条案例，这两批上 v75 默认预测都来自更早的 v74 训练，因而对 v75 本身是样本外的。73 个运行时无 gold 特征、216 个模型配置和 7 个阈值组成 1512 个有限策略。选中配置为 100 棵树、深度 2、最小叶 25、学习率 0.1、Huber 损失、`magnitude_x20` 权重、阈值 0.0025。五折 OOF F1 为 `0.540164`，相对 v75 为 `+0.005913`，95% CI `[+0.004067,+0.007857]`；该结果参与模型选择，只能视为开发诊断。

开发时还发现并修复了可移植树遍历器的边界比较问题：NumPy `float32` 标量直接与 Python `float` 阈值比较时可能把阈值回缩到 float32，导致极接近阈值的样本走错子节点。v81 本地遍历器在比较前显式提升特征标量，并通过真实失败样本和专门回归测试证明与 sklearn 预测一致。旧版冻结实现未被修改。

## 冻结与泄漏控制

在选择任何 v81 目标 ID 前，协议、源登记、模型、路由与传输代码、运行脚本和定向测试已按字节数及 SHA-256 锁定。目标源为 2WikiMultiHopQA `dev.parquet`，两阶段原计划各 800 条、四题型各 200 条。两阶段都永久排除以下互斥历史：

| 排除来源 | 案例数 |
| --- | ---: |
| 早期公共参考池 | 1000 |
| v74 开发 | 800 |
| v75 开发 | 800 |
| v75 确认 | 800 |
| 合计 | 3400 |

开发集按冻结盐值和 ID 排序抽取，四题型各 200 条，与 3400 个既往 ID 重叠为 0，共包含 25875 个候选段落。模型侧盲文件不含答案、gold 证据 ID、gold 标记或 gold 角色。冻结 BGE embedding/reranker 在 GPU 上完成 800/800 条评分，评分文件在 gold 联结前落盘并登记 SHA-256。

## 开发集结果

| 方法 | 证据宏 F1 | 证据宏召回 | 完整证据召回 | 平均 tokens |
| --- | ---: | ---: | ---: | ---: |
| v81 残差三路由 | 0.547195 | 0.851000 | 0.658750 | 126.431250 |
| v75 问题路由 | 0.542751 | 0.846000 | 0.645000 | 126.410000 |
| 词法问题路由 | 0.540965 | 0.842875 | 0.638750 | 126.397500 |
| 软标题闭包 v74 | 0.525358 | 0.820438 | 0.620000 | 125.936250 |
| 交替锚点 | 0.517751 | 0.802250 | 0.556250 | 125.356250 |

v81 的动作分布为默认 518、软/锚翻转 202、cross 覆盖 80；实际路由为软闭包 519、交替锚点 201、cross 80，三路均达到实质覆盖。候选完整证据召回相对 v75 提高 `0.013750`，没有无效选择器输出，成本门也通过。

分题型相对各自最佳登记对照的差值为：

- bridge comparison：`+0.017778`；
- comparison：`-0.008571`；
- compositional：`-0.001429`；
- inference：`-0.001429`。

失败的严格门槛是：相对最强对照/v75 的点增益 `+0.004444` 未达到 `+0.005`，以及 comparison 的 `-0.008571` 未达到 `-0.005` 分层安全线。因为最强总体对照就是 v75，这对应 3 个布尔检查失败，但只有两个独立科学原因。

## 研究边界与后续方向

v81 支持的最强结论是：在新的案例互斥 2Wiki 样本上，残差路由器相对 v75 获得了区间为正的小幅提升，同时提高完整证据召回并保持全部非劣条件；但它没有达到预注册的 0.5 个百分点实际优势线，comparison 题型也存在超过严格安全线的退化。

因此 v81 确认阶段关闭，开发样本不得被重新包装成 v81 确认。后续若继续研究，必须登记为新版本，把 v81 开发集明确标为训练/诊断数据，并从剩余未触碰 2Wiki 容量另取新样本；不得修改 v81 门槛后声称本轮通过。

本轮不是独立数据集、官方 2Wiki 榜单、答案生成质量、真实 SetR、洪水领域专家或生产证据。完整机器证据位于协议、源登记、实现锁、模型开发、执行、结果、关闭记录，以及 `output/rag_evaluation/twowiki_residual_router_v81/development/` 下的结果、报告和逐例压缩证据。
