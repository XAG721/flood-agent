# 安全、隐私与故障处置手册

依赖供应链审计与当前修复基线见 `dependency_security_audit.md`。CI 必须保持 Python、主前端和 Cesium 前端已知高危漏洞为 0；自动公告审计不能替代第三方渗透测试。

## 保护范围

联系方式、特殊人群、精确位置、文档原件/OCR、审批、执行证据和审计链均按数据分类与岗位最小权限处理。响应域载荷认证加密；普通用户不能更新或删除预警快照、风险对象主数据版本/导入记录、CandidateObjectListVersion、文档源/解析/生命周期/索引、任务 Schema/规则集契约、审批、反馈、任务版本、分派和时间线。

风险对象文件导入只允许业务复核岗或管理员使用 AAL2。服务在请求解析前限制请求体，并在读取工作簿前校验文件名、MIME、Base64、SHA-256、ZIP 成员路径/数量/解压量/压缩比，拒绝宏、外链和公式。文件原文不落库；只保存认证加密的规范对象、来源哈希、逐对象内容哈希和行级隔离原因。发现异常压缩包、哈希不符、异常隔离率或非预期大批 STALE 时，应暂停继续导入并按事件响应流程核对来源文件。

文档上传允许的格式限于 TXT/Markdown、CSV、XLSX、DOCX、PDF 和扫描图片，解码后默认不超过 10 MiB。服务校验安全文件名、MIME、Base64、SHA-256、OOXML ZIP 路径/成员/解压量、PDF 签名和图片完整性；扫描件必须携带经受控适配器或人工复核的 OCR 文本及引擎版本。原始字节与 OCR 文本认证加密保存，但任何列表/历史接口都不得回显这些字段。文档发布要求解析成功和复核权限；日期损坏、未来生效、过期、替代、退役和失败状态在检索入口再次失败关闭。

## 事件响应

1. 发现越权、非法状态转换、载荷哈希不一致或审计缺失时立即 No-Go。
2. 关闭受影响功能开关，暂停下发并保留所有 Outbox、审批和反馈记录。
3. 创建数据库备份和审计归档，验证签名、文件哈希、解密和 SQLite 完整性。
4. 核对事件、风险对象主数据/版本/隔离区、STALE CandidateRun、任务、Outbox、回调和通用幂等账本数量；`INDETERMINATE` 记录必须结合资源引用与审计链人工对账，不得删除记录后盲目重放，也不得手工修改正式状态表恢复演示。
5. 若出现任务引用清单版本不一致，核对最新预警修订、CandidateRun 状态、对象版本与核验哈希；禁止修改历史冻结清单或降级到旧版本继续成案。
6. 若出现文档索引异常，核对原始文件 SHA-256、解析哈希、生命周期和最后成功 IndexBuild；失败的重建不得覆盖有效索引，疑似恶意文件或未核验 OCR 应保持草稿/失败状态并隔离来源。
7. 在隔离数据库恢复并复现故障，修复后执行全量安全、状态机和回归测试。
8. 记录原因、范围、负责人、恢复动作和最终证据；由授权人员决定恢复功能开关。

## 密钥与备份

生产必须通过 `FLOOD_DATA_ENCRYPTION_KEY` 或真实 KMS 管理密钥。轮换前创建受保护恢复点；环境托管密钥轮换处于待激活状态时，旧密钥重启必须失败关闭。备份跨主机导入需同时通过 HMAC 清单、SHA-256、数据库完整性和解密验证。

通用 `IdempotencyRecord` 的请求哈希、响应体和资源引用属于受保护运行数据，使用与响应域相同的认证加密并纳入在线重加密。幂等作用域含操作者、岗位、终端、方法和路径，禁止跨身份返回已保存响应；运维日志只记录记录 ID、状态和摘要，不输出请求或响应明文。

## 外部依赖边界

生产 TLS、真实 IdP/AAL2、KMS 和异地主机恢复必须在目标环境取得真实证据。本地开发断言、测试证书或同机恢复不能替代生产验收。
