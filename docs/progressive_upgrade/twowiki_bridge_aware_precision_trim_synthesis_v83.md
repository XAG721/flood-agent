# 2Wiki 桥接感知精度裁剪前瞻验证（v83）

## 结论

v83 验证了一个范围明确的机制：在冻结 v82 证据顺序和路由不变的前提下，仅根据问题文本识别 bridge-comparison，并把该类案例的保留证据数从 5 裁剪为 4，可以稳定提高证据精度并降低上下文成本。开发阶段 18 项严格门全部通过，因而按预注册规则打开确认；确认阶段相对最强登记对照 v82 的 F1 增益仍为正且置信区间不跨零，但候选绝对 F1 为 `0.549420`，比预注册下限 `0.550000` 低 `0.000580`。因此最终状态固定为：

`2WIKI_V83_PRECISION_TRIM_CONFIRMATION_ADVANTAGE_NOT_ESTABLISHED`

确认集不得用于降低门槛、重选阈值或重新包装确认。选择器、CANARY、DEFAULT 和生产采用均不授权，Gate 2 保持 `NO-GO/SHADOW`。

## 机制与模型开发

v82 的开发结果表明其路由选择已接近逐例路由上限，剩余主要误差来自固定 Top-5 带来的精度损失。2Wiki 的 bridge-comparison 证据通常需要四个 supporting facts，而其他题型通常需要两个；v83 因此不再改动路由，而是在冻结 v82 输出之后增加一个单一动作：

- 运行冻结 v82，保留其证据排序和实际路由；
- 冻结问题文本分类器的 bridge 概率不低于 `0.3` 时保留前 4 条；
- 其余案例保留全部 5 条；
- 运行时不读取官方题型、答案、gold evidence 或任何结果后特征。

模型开发只使用已永久排除的 v75 开发、v75 确认、v81 开发和 v82 开发共 3,200 例。有限搜索覆盖 16 个分类器配置和 112 个裁剪策略，最终选择哈希维度 `64`、L2 `32.0`、阈值 `0.3`。五折样本外诊断为：

| 指标 | 冻结 v82 | v83 候选 | 差值 |
| --- | ---: | ---: | ---: |
| Evidence Macro F1 | 0.544825 | 0.554477 | +0.009652 |
| Evidence Macro Recall | 0.845771 | 0.833130 | -0.012641 |
| Complete Evidence Recall | 0.647500 | 0.622500 | -0.025000 |
| Mean Selected Tokens | 126.532500 | 120.461875 | -6.070625 |

相对 v82 的配对 bootstrap 95% CI 为 `[+0.007831,+0.011496]`。四个训练批次的 F1 差值均为正，分别为 `+0.007888/+0.010341/+0.009947/+0.010432`；bridge 分类平衡准确率为 `0.989583`。这些数值参与模型选择，只是开发证据，不是目标确认。

## 预注册与冻结边界

在选择任何 v83 目标 ID 前，协议、来源登记、模型产物、路由实现、迁移实现、两个运行器和四个实现/锁测试完成冻结。九文件锁 SHA-256 为：

`3c0eea0c1dfd960139332a7461522a76b8036a6ef6cd01503ff0d69bb7271bc9`

目标源固定为 2WikiMultiHopQA dev 的 12,576 条记录。历史池 1,000 条、v74 800 条、v75 开发/确认各 800 条、v81 开发 800 条和 v82 开发 800 条形成 5,000 个两两互斥永久排除 ID。开发和确认各 800 例，四题型各 200 例；二者彼此及与全部历史 ID 零重叠。12 个登记对照、18 项严格门、5 项非劣包络、样本盐值和 bootstrap 种子均在目标前冻结。

## 可支持与不可支持的陈述

v83 支持：

- 问题文本 bridge 分类在两个案例互斥目标阶段均达到约 `0.99` 平衡准确率；
- 固定 v82 路由和排序后进行 4/5 条桥接感知裁剪，在开发和确认阶段都显著提高 Evidence Macro F1，并减少约 5.6—5.8 个平均 selected tokens；
- 该机制在预注册非劣包络内，没有触发题型、完整召回、总体召回、无效输出或成本安全失败。

v83 不支持：

- 不支持声称全部确认门已通过或已经建立可采用的稳定优势；
- 不支持根据确认结果把绝对 F1 门槛降到 `0.549`、改阈值或复用确认样本重跑；
- 不支持独立数据集泛化、官方 2Wiki 榜单、答案生成质量、真实 SetR 复现或洪水领域有效性；
- 不支持选择器上线、CANARY、DEFAULT、自动业务决策或生产部署。

后续若继续研究，必须登记新版本，在选择新的未触碰案例前冻结不同且可证伪的机制；v83 开发与确认共 1,600 个目标 ID 应永久排除。由于当前未触碰 inference 容量只剩 49 条，不能再按四题型各 200 例复制同规模两阶段实验，后续应优先登记独立公共数据源或改变预注册样本设计，而不是复用 v83 个案。
