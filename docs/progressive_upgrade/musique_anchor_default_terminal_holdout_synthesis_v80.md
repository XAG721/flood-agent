# MuSiQue 锚点默认三路由终局留出实验综合报告（v80）

## 结论

v80 完成了“仅用永久排除的 v78+v79 目标域证据开发锚点默认三路由器，再在剩余 MuSiQue 容量上进行一次终局、案例互斥的前瞻留出评估”的预注册实验。600 条终局样本上的候选证据宏 F1 为 `0.527817`，最强登记对照是冻结 v79 路由器的 `0.526257`；配对差值仅为 `+0.001561`，95% CI 为 `[-0.002533,+0.005774]`。候选完整证据召回为 `0.643333`，高于 v79 的 `0.630000`，但总体 F1 低于预注册绝对下限 `0.55`，相对最强对照的点增益和区间门也均未通过。

2/3/4-hop 相对各跳最强控制的差值为 `+0.003571/-0.006667/+0.004444`；其中 3-hop 低于严格安全线 `-0.005`，但仍高于次级非劣线 `-0.02`。零重叠、零无效输出、三路覆盖、最大路由占比和 Token 成本条件全部通过，次级非劣包络五项全部通过。冻结状态为：

`MUSIQUE_V80_ANCHOR_DEFAULT_TERMINAL_HOLDOUT_ADVANTAGE_NOT_ESTABLISHED`

v80 不开放第二个同源确认阶段，也不得把这 600 条终局样本用于修改模型、阈值、特征、门槛或选择器后重新声称确认。选择器、CANARY、DEFAULT 和 Gate 2 均不授权，Gate 2 保持 `NO-GO/SHADOW`。

## 模型开发边界

模型只使用已揭示并永久排除的 v78 600 条与 v79 470 条 MuSiQue 案例，共 1,070 条。运行时仍使用 71 个不含 gold 的图结构、检索分数和选择集合重叠特征，但将交替锚点改为默认路由，分别学习 cross-encoder 与软标题闭包相对锚点的 F1 增益。

有限网格由以下配置组成：

- 树数：25、50、100；
- 深度：1、2；
- 最小叶：25、50、100；
- 学习率：0.05、0.1；
- 损失：Huber、平方损失；
- 样本权重：均匀、非零增益四倍、增益幅度二十倍；
- 共享阈值：0、0.0025、0.005、0.0075、0.01、0.015、0.02。

216 个模型配置与 7 个阈值形成 1,512 个路由策略，使用固定 SHA-256 五折 OOF；搜索只接受各 hop 相对锚点不低于 `-0.005`、至少两路有实质覆盖且非全锚点的策略。选中配置为 50 棵树、深度 2、最小叶 50、学习率 0.1、平方损失、增益幅度二十倍权重、阈值 0.0025。其 OOF 模型选择诊断为：

- 候选 F1：`0.554843`；
- 相对锚点：`+0.005544`，95% CI `[+0.002129,+0.009068]`；
- 完整证据召回：`0.585047`；
- 路由分布：锚点 525、cross-encoder 288、软闭包 257；
- v78/v79 两个训练子集相对锚点：`+0.004755/+0.006552`。

这些数值参与模型和阈值选择，只能作为开发诊断，不能解释为独立确认。

## 来源、锁定与盲评

来源仍为固定 SHA-256 的 MuSiQue full v1.0 train answerable 行。样本选择永久排除：

- v65—v73 已登记的 16,900 个来源承诺；
- v77 的 800 条目标域校准样本；
- v78 的 600 条目标域训练/模型选择样本；
- v79 的 470 条目标域训练/模型选择样本。

总排除量为 18,770，剩余未触碰 answerable 容量为 1,168 条，其中 2/3/4-hop 为 778/317/73。由于 4-hop 只剩 73 条，无法支撑两个具有可比配额的阶段，v80 在读取任何目标 ID 前就登记为单次终局留出，配额为 400/150/50；运行后仅剩 378/167/23，禁止再包装为同源确认。

模型、阈值、实现、协议、来源登记、600 例规模、配额、九个控制、门槛和测试在目标 ID 选择前以 SHA-256 锁定。锁审计 15 项通过后才首次选择样本。终局集包含 600 条、11,998 个候选段落，与四类排除集合的重叠均为 0；盲输入不含答案、官方分解、supporting 标记或 gold ID。

冻结 `BAAI/bge-large-en-v1.5` 与 `BAAI/bge-reranker-large` 在 RTX 4060 Ti 上完成 600/600 条评分，耗时 `1609.665096` 秒。正式评分文件 SHA-256 为 `68726aa7c6d788e867f2e395f628dffd17261556e143c92bf4b3a182917f80c1`。选择输出在连接密封 gold 前写定，非法选择为 0。

候选相对 cross-encoder 提高 `+0.010060`，95% CI `[+0.003479,+0.016700]`；相对交替锚点提高 `+0.006501`，95% CI `[+0.001594,+0.011587]`；相对 v78 提高 `+0.007884`，95% CI `[+0.001991,+0.013935]`。这些比较说明锚点默认重构稳定优于若干较早方法，但预注册主比较对象是所有公平控制中的最强者 v79，因此不能用较弱控制的显著增益替代未通过的主门槛。

候选路由分布为锚点 273、cross-encoder 186、软闭包 141，占比 45.5%/31.0%/23.5%，三路均有实质使用。全部次级非劣条件成立，但以下严格门失败：

- F1 `0.527817 < 0.55`；
- 相对最强对照点增益 `+0.001561 < +0.005`；
- 相对最强对照的 95% CI 下界 `-0.002533 <= 0`；
- 相对冻结 v79 的点增益与区间门同样失败；
- 3-hop 差值 `-0.006667 < -0.005`。

## 解释边界

v80 支持的最强结论是：把强交替锚点设为默认路由，并用目标域历史学习两个覆盖增益，在终局新样本上保持了相对最强 v79 的非劣点估计、提高完整证据召回，并显著超过 cross-encoder、直接锚点和 v78；但它没有建立相对最强登记对照至少 0.5 个百分点且区间为正的优势，3-hop 也略低于严格安全线。

本轮不是零目标调参，因为 v78+v79 共 1,070 条目标域证据参与了模型选择；也不是独立训练数据确认、官方 MuSiQue 榜单、答案生成质量、真实 SetR、洪水领域专家或生产证据。v80 终局结果只能用于报告和研究边界判断，不得进入后验修复循环。

完整机器证据位于协议、来源登记、实现锁、模型开发、执行、结果、关闭记录，以及 `output/rag_evaluation/musique_anchor_default_v80/terminal_holdout/` 下的结果、报告和逐例压缩证据。
