# 区县防办响应闭环用户操作手册

## 正常流程

1. 值班员确认页面顶部始终显示“受控模拟环境”，核对事件号、预警版本、来源和数据版本。
2. 在“待核验风险对象”运行筛查。无预警多边形时系统明确降级为区域台账模式；候选仍需人工确认。
3. 预警更新后对象显示 `STALE`，必须重新筛查和核验，旧确认不能直接用于新草案。
4. 对已确认对象生成证据草案。证据工作台逐字段显示“有支持/有冲突/缺失”。
5. 如有冲突，复核或审批岗位选择合法来源并填写裁决理由；裁决产生新证据包版本。
6. 草案提交前查看规则校验。`HARD_BLOCK` 不可提交；`SOFT_WARNING` 需审批人员明确确认。
7. 审批人员核对任务、对象、责任、四类时限、依据、证据包和载荷哈希。高风险批准要求 AAL2 和理由。
8. 模拟下发写入 Outbox；“已送达”仅代表模拟接口接收，不代表真实跨部门接入。
9. 联络员确认接收并分派现场执行人。只有被分派执行人可以开始和反馈。
10. 执行人可以报告部分完成、资源不足、受阻或完成；部分完成保持任务可继续。
11. 延期由执行或联络岗位申请，由独立复核/审批岗位决定。
12. 通信或系统异常时，复核/审批岗位可人工接管；撤回任务仅授权审批岗位使用并要求理由。
13. 完成证据由独立人员核验；退回后继续执行，核验通过进入终态。
14. 全部必需任务完成、豁免或经授权撤回后，事件才可关闭并生成复盘草稿与场景报告。

## 故障处理

- `VERSION_CONFLICT`：刷新页面，比较新版本后重新编辑，不覆盖他人修改。
- `RULE_HARD_BLOCK`：按规则明细补证、处理冲突或修正字段，不可绕过。
- Outbox `failed`：检查审批载荷哈希，不允许把失败直接改成成功；转人工接管并对账。
- RAG/模型不可用：使用人工结构化草案和人工证据组装，确定性状态机继续运行。
- 地图不可用：使用对象列表继续核验和处置。
- 身份或审计服务异常：失败关闭，不使用旧页面修改新版状态。
