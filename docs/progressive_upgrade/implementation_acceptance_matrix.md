# 渐进式迭代实现与验收矩阵

状态定义：

- `本地已验证`：实现存在，且有当前自动测试、构建、脚本或生成报告证据。
- `受控模拟已验证`：仅证明模拟场景，不外推到真实部门或生产环境。
- `条件完成`：代码与本地证据完成，但切换仍受 Gate 或外部环境约束。
- `外部 No-Go`：必须由真实机构、生产基础设施或独立人员提供证据，仓库不能代替。

## 关键安全不变量

- Core API 是响应域新表唯一业务写入口；Legacy Adapter 只读并记录调用。
- AI/RAG 只能产生候选、证据和草案，不能写审批、下发或任务状态。
- 未确认或 STALE 对象不能成案；未冻结/缺失/冲突证据不能通过硬门禁。
- 审批绑定任务版本、任务载荷 SHA-256、证据包 SHA-256、规则集和检查记录。
- Outbox 发送前重算载荷哈希，哈希不一致失败关闭；唯一幂等键阻止重复发送。
- 执行人、草案起草人、审批人、延期审批人和完成核验人按场景职责分离。
- 非法状态迁移由集中状态机拒绝；终态没有出边。
- 模拟网关拒绝 HTTP(S) 等非 `simulated://` 目的地。

## 最终完成边界

仓库层面的首期受控模拟闭环可以实现并自动回归；以下事项不属于可由代码伪造的“完成”：真实预警与 GIS 权威数据、生产 PostgreSQL/PostGIS 切换、真实 IdP/MFA、生产 TLS/KMS、真实跨部门下发、第三方安全评估、异地主机恢复、两名独立业务专家标注与第三方裁决、旧生产流量归零和账号撤权。它们必须保持外部 No-Go，直到取得真实运行证据。
