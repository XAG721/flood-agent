- 升级前提交 `2db016a` 已完成离线重建冻结：Git tree/archive、四类重建输入、SQLite 逐表 Schema/内容哈希和 22 篇 RAG 索引摘要均在 `output/acceptance/legacy_baseline_manifest.*`，实际二进制不进入 Git。
- Python 全量测试：248 项通过（GitHub CI 持续复验）；响应工作流、通用幂等、风险对象主数据、候选冻结清单、文档治理、证据治理与文件请求边界专项均纳入全量回归。
- 前端全量测试：19 项通过；Chromium E2E 2 项通过，其中新版工作台在真实页面刷新后复核同一事件、预警版本和模拟水印。
- 前端生产构建：通过。
- 安全专项测试覆盖：密文落盘、密文篡改拒绝、哈希链校验、不可删除触发器、备份权限、文件哈希、数据库完整性、密钥匹配、跨实例导入、隔离恢复和加密密钥轮换。
- RAG 专项测试：BM25、Dense、混合、MMR、Rerank、覆盖贪心代理、FRC-RAG 证据选择、神经/公开评测辅助逻辑、消融及独立标注约束均有自动测试；覆盖贪心代理不是 SetR 复现。报告位于 `output/rag_evaluation/`，空白标注包位于 `output/rag_annotation/round-1/`。
- 神经向量实测：`BAAI/bge-small-zh-v1.5`；Neural Dense Recall 0.7222、Role Coverage 0.8333；Neural Hybrid RRF 指标相同；FRC-RAG 选择器在同一小型集上 Recall/Role Coverage 为 1.0。
- 公开全量可评测集：MultiHop-RAG Hybrid Recall 0.6237/完整集 0.3082；ConditionalQA Dense Recall 0.2627/完整集 0.1292；HotpotQA Dense Recall 0.8866/完整集 0.7815。
- 真实 BGE/reranker 参考审计：ConditionalQA、MultiHop-RAG、HotpotQA 上 FRC 相对各自最强可复现基线的 Evidence F1 配对 95% CI 均跨 0；流水线可行，但优势未获证明，Gate 2 保持 `NO-GO/SHADOW`。
- 真实模型消融/敏感性审计：9/9 命名消融已运行，但 Full 仍低于 `w/o Role`，CONFLICTS Full 也低于 `w/o Conflict`。HousingQA Full 相对 `w/o Field` 字段覆盖提高 0.050000（95% CI [+0.018750, +0.087500]），却与最强字段分解基线持平且 Answer Accuracy 仅 0.306250；在同一 40 例冻结真实模型分数上，字段权重 0/0.5/1/2/4/8 的 Evidence F1 为 0.656250/0.681250/0.687500/0.706250/0.712500/0.712500，角色权重 0/0.5/1/2/4 的角色覆盖为 0.600000/0.616667/0.625000/0.633333/0.633333，两个维度可辨识但高于冻结参数的最大 F1 增益仅 0.006250。LawShift Full 相对无版本过滤精确证据提高 0.137097（95% CI [+0.080645, +0.201613]），却与公平过滤基线持平且 Article Recall@1 下降 0.064516。EUR-Lex/CELLAR Full 相对无适用性过滤精确证据提高 0.516667（95% CI [+0.383333, +0.650000]），权威生效/失效日期已可识别，但 Full 与公平日期过滤基线同为 1.000000。K、Token、缺失、分块、冲突阈值和权重技术矩阵已覆盖；跨领域事后权重扫描不计为真实防汛专家证据，也不改变 Gate 2。
- 分块长度真实重评分：64/128/256-token 下 FRC Evidence F1 为 0.614475/0.632662/0.679077，相对最强覆盖贪心代理差值为 -0.000379/-0.000038/-0.001155，三档 95% CI 均跨 0；FRC 重复父证据率随分块增大由 0.324912 降至 0.122807。
- Token/缺失敏感性：三套数据 512/1024/2048 Token 预算均零超限，FRC 未呈现稳定优势；ConditionalQA 25/50/75% 目标缺失的实际删除率为 27.25%/51.63%/76.12%，25% 档错误完整声明率仍为 0.723005。
- CONFLICTS 全量审计：覆盖贪心代理 Accuracy 0.344978，FRC 0.334061；FRC - 基线为 -0.010917，95% CI [-0.043668, +0.024017]。FRC 过时类型 Recall 0.564516，低于代理的 0.693548，因此不能据此切流。

## 后续完成门槛

V3 的受控模拟首期目标已经完成；以下生产和研究条件仍需外部证据：

1. 接入专业部门真实预警多边形和经审核的对象坐标，并完成空间数据质量与坐标权限验收；
2. 使用实际生产证书和可信反向代理完成 HTTPS 部署验收；
3. 使用真实身份提供方完成 MFA/WebAuthn 登录与 AAL2 断言联调，而不是开发代理签名；
4. 在真实密钥管理系统中执行一次加密密钥轮换和回滚演练；代码层已覆盖待激活重启拒绝、提升新密钥和旧备份恢复；
5. 在真实异地主机执行灾备文件传输与恢复时效测量；代码层跨实例导入和恢复已通过；
6. 完成公开 benchmark 的答案生成官方口径对齐与独立区县人工标注，形成可发表的正式对比结论。
